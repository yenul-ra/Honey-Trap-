# Bee Swarm Simulation 

A Python tool for analysing data produced by the Bee Swarm Simulation.

The project explores how a group of simple agents can work together to solve a complex problem without centralised control.

## Core Idea

The analyser helps study how information moves through a swarm while the bees explore a maze.

It focuses on questions such as:

* How quickly can the swarm discover an exit?
* How much of the maze needs to be explored before finding it?
* How does information spread between individual bees?
* Which communications appear to contribute to finding or spreading the exit route?
* How does swarm size affect collective performance?

## What It Analyzes

The analyzer can examine:

* Maze exploration
* Exit discovery time
* Discovery percentage
* Bee-to-bee communication
* Information propagation
* Useful and non-useful communication
* Individual bee activity
* Communication efficiency
* Trade-offs between exploration and discovery speed
